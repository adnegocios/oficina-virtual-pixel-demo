# Oficina Virtual Pixel — demo en línea

Demo de la oficina en pixel art de Ad-negocios: seis agentes de Claude Code simulan un cierre mensual completo.

**Ver la demo:** https://adnegocios.github.io/oficina-virtual-pixel-demo/

Esta página es solo la demo: los eventos son simulados y no se conecta a ningún servidor. Se genera con `scripts/exportar-demo.js` desde el proyecto principal, que es privado.

Sprites, fuente y escenario dibujados en código; todo es original. Licencia MIT.
